Personal Oura Data Application

Privacy Policy

Effective July 29, 2026

Overview

This application is a private, non-commercial project used solely by its developer to access and analyze the developer's own Oura Ring data. It is not offered to the public and does not create user accounts.

Data accessed

The application accesses only the Oura data that the developer authorizes through the Oura API. This may include wellness, sleep, readiness, activity, and related account data made available by that authorization.

How data is used and stored

Oura data is used only for the developer's personal analysis. Data retrieved from the Oura API is stored locally on the developer's computer and is not used for advertising, profiling, or any commercial purpose.

Sharing and third parties

The application does not sell, rent, share, or disclose Oura data to third parties. It does not use third-party analytics, advertising services, or tracking technologies.

Retention and deletion

Locally stored Oura data is retained only for as long as it is useful for personal analysis. It can be deleted by removing the local files, and the application's access can be revoked through the connected Oura account.

Security

Reasonable care is taken to keep locally stored data and API credentials private. No method of electronic storage is completely secure, however, so absolute security cannot be guaranteed.

Changes to this policy

If the application's purpose, availability, or data practices change, this policy will be revised and the effective date above will be updated accordingly.

Contact

Questions about this policy may be sent to asramani [at] mit [dot] edu.
